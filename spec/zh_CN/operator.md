# Vanillang 运算符

这些符号用于表示基本的运算操作，或对运算符重载函数的调用。

## 数学运算符

| 运算符 | 描述                                                           | 是否支持重载 | 重载参数个数 | 重载参数类型                   | 重载返回值类型                                           |
| ------ | -------------------------------------------------------------- | ------------ | ------------ | ------------------------------ | -------------------------------------------------------- |
| `+`    | 二元运算符，用于两数相加，也可用于字符串拼接；也作为一元运算符 | 是           | 0 或 1       | 若有则为任意非 `Optional` 类型 | 参数个数为 0 时必须返回操作数的类型，参数个数为 1 时不限 |
| `-`    | 二元运算符，用于两数相减；一元运算符，用于数值取反             | 是           | 0 或 1       | 若有则为任意非 `Optional` 类型 | 参数个数为 0 时必须返回操作数的类型，参数个数为 1 时不限 |
| `*`    | 二元运算符，用于两数相乘                                       | 是           | 1            | 任意非 `Optional` 类型         | 不限                                                     |
| `/`    | 二元运算符，用于两数相除，结果为浮点数                         | 是           | 1            | 任意非 `Optional` 类型         | 不限                                                     |
| `//`   | 二元运算符，用于两数整除，结果向下取整                         | 是           | 1            | 任意非 `Optional` 类型         | 不限                                                     |
| `%`    | 二元运算符，用于两数取模，结果符号与除数相同                   | 是           | 1            | 任意非 `Optional` 类型         | 不限                                                     |
| `**`   | 二元运算符，用于幂运算                                         | 是           | 1            | 任意非 `Optional` 类型         | 不限                                                     |

## 比较运算符

| 运算符 | 描述                                                                      | 是否支持重载 | 重载参数个数 | 重载参数类型       | 重载返回值类型 |
| ------ | ------------------------------------------------------------------------- | ------------ | ------------ | ------------------ | -------------- |
| `==`   | 等于运算符，比较两个值是否相等                                            | 是           | 1            | 与左表达式类型相同 | `bool`         |
| `!=`   | 不等于运算符，比较两个值是否不相等                                        | 否           | -            | -                  | -              |
| `===`  | 相同运算符，比较两个引用类型的值是否引用同一个对象，不能用于 `any` 类型   | 否           | -            | -                  | -              |
| `!==`  | 不相同运算符，比较两个引用类型的值是否引用不同的对象，不能用于 `any` 类型 | 否           | -            | -                  | -              |
| `<`    | 小于运算符，比较左值是否小于右值                                          | 是           | 1            | 与左表达式类型相同 | `Ordering?`    |
| `>`    | 大于运算符，比较左值是否大于右值                                          | 是           | 1            | 与左表达式类型相同 | `Ordering?`    |
| `<=`   | 小于等于运算符，比较左值是否小于或等于右值                                | 是           | 1            | 与左表达式类型相同 | `Ordering?`    |
| `>=`   | 大于等于运算符，比较左值是否大于或等于右值                                | 是           | 1            | 与左表达式类型相同 | `Ordering?`    |

## 逻辑运算符

| 运算符 | 描述                                             | 是否支持重载 | 重载参数个数 | 重载参数类型 | 重载返回值类型 |
| ------ | ------------------------------------------------ | ------------ | ------------ | ------------ | -------------- |
| `&&`   | 逻辑与运算符，左值和右值都为真时结果为真         | 否           | -            | -            | -              |
| `\|\|` | 逻辑或运算符，左值和右值有一个为真时结果为真     | 否           | -            | -            | -              |
| `!`    | 逻辑非运算符，值为真时结果为假，值为假时结果为真 | 否           | -            | -            | -              |

## 位运算符

| 运算符 | 描述                                                                   | 是否支持重载 | 重载参数个数 | 重载参数类型       | 重载返回值类型     |
| ------ | ---------------------------------------------------------------------- | ------------ | ------------ | ------------------ | ------------------ |
| `&`    | 位与运算符，对两个整数的每一位执行逻辑与操作                           | 是           | 1            | 与左表达式类型相同 | 与左表达式类型相同 |
| `\|`   | 位或运算符，对两个整数的每一位执行逻辑或操作                           | 是           | 1            | 与左表达式类型相同 | 与左表达式类型相同 |
| `^`    | 位异或运算符，对两个整数的每一位执行逻辑异或操作                       | 是           | 1            | 与左表达式类型相同 | 与左表达式类型相同 |
| `~`    | 位非运算符，对一个整数的每一位执行逻辑非操作                           | 是           | 0            | -                  | 与左表达式类型相同 |
| `<<`   | 算术左移运算符，将一个整数的二进制表示向左移动指定的位数               | 是           | 1            | `int`              | 与左表达式类型相同 |
| `>>`   | 算术右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补符号位 | 是           | 1            | `int`              | 与左表达式类型相同 |
| `>>>`  | 逻辑右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补 0     | 是           | 1            | `int`              | 与左表达式类型相同 |

## 其他运算符

| 运算符       | 描述                                                                                                             | 是否支持重载 | 重载参数个数 | 重载参数类型                                                     | 重载返回值类型                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------- | ------------ | ------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `.`          | 成员访问运算符，用于访问作用域内的标识符                                                                         | 否           | -            | -                                                                | -                                                                               |
| `?.`         | 安全成员访问运算符，用于访问 `Optional` 对象的属性或方法，如果对象为 `none` 则返回 `none`                        | 否           | -            | -                                                                | -                                                                               |
| `[]`         | 索引访问运算符，用于访问数组、列表或字典的元素；切片访问运算符，用于访问字符串的子串                             | 是           | 1 或 2       | 第一个参数为任意非 `Optional` 类型，第二个参数如果有则为元素类型 | 只有一个参数时返回 `Optional<T>`， 其中 `T` 为元素类型，有两个参数时返回 `void` |
| `()`         | 函数调用运算符，用于调用函数或方法                                                                               | 是           | 不限         | 不限                                                             | 不限                                                                            |
| `?:`         | 条件表达式运算符，根据条件表达式的值选择返回结果                                                                 | 否           | -            | -                                                                | -                                                                               |
| `??`         | 空值合并运算符，当左值不为 `none` 时返回左值，否则返回右值，左值需为 `Optional` 类型，右值不能为 `Optional` 类型 | 否           | -            | -                                                                | -                                                                               |
| `..`         | 范围语法，用于生成一个包含起始和结束值的 `Range` 结构，仅当作用于基本的整数类型时可以省略一个边界                | 是           | 1            | 与左表达式类型相同                                               | `Range<T>`，其中 `T` 为 `this` 的类型                                           |
| `instanceof` | 判断一个对象的运行时类型                                                                                         | 否           | -            | -                                                                | -                                                                               |

**附：Vanillang 可重载运算符文法产生式**

```ebnf
OverloadableOperator ::= '+' | '-' | '*' | '/' | '//' | '%' | '**' | '==' | '<=>' | '&' | '|' | '^' | '~' | '<<' | '>>' | '>>>' | ('(' ')') | ('[' ']') | '..';
```

**附：Vanillang 运算符优先级及结合方式**

| 优先级 | 运算符                             | 结合方式 |
| ------ | ---------------------------------- | -------- |
| 1      | `()`、`[]`、`.`、`?.`              | 左结合   |
| 2      | `**`                               | 右结合   |
| 3      | `!`、`~`、`-`（单目）、`+`（单目） | 右结合   |
| 4      | `*`、`/`、`//`、`%`                | 左结合   |
| 5      | `+`、`-`                           | 左结合   |
| 6      | `<<`、`>>`、`>>>`                  | 左结合   |
| 7      | `&`                                | 左结合   |
| 8      | `^`                                | 左结合   |
| 9      | `\|`                               | 左结合   |
| 10     | `..`                               | 左结合   |
| 11     | `<`、`<=`、`>`、`>=`、`instanceof` | 左结合   |
| 12     | `==`、`!=`、`===`、`!==`           | 左结合   |
| 13     | `&&`                               | 左结合   |
| 14     | `\|\|`                             | 左结合   |
| 15     | `??`                               | 左结合   |
| 16     | `?:`                               | 右结合   |

---

注：
1. 本文中所有非语言内置类型，均为标准库模块 `vanillang.types` 下的自定义类型，统一省略前缀
2. 四个比较运算符重载使用符号 `<=>`，该重载返回 `Ordering?` ，为 `None` 时表示无法比较，否则 `Some(value)` 中的 `value` 含义如下：
    - `Ordering.Less` 表示小于
    - `Ordering.Equal` 表示等于
    - `Ordering.Greater` 表示大于
3. 比较运算符重载不适用于 `==`，`Ordering.Equal` 仅用于判断 `<=` 和 `>=` 中的等号是否成立
4. `!=` 在 `==` 重载存在时可用，返回 `==` 返回值的逻辑非
5. `[]` 的双参数重载仅在赋值语句中有效，且左边是一个索引访问表达式
