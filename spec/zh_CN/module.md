# Vanillang 模块

## 概述

模块是 Vanillang 的基本组织单位，一个模块对应一个源文件。

Vanillang 的源文件以 `.vnl` 作为扩展名，包含了 Vanillang 代码和注释。

- 一个源文件可以包含多个语句、函数、类等定义，以及任意数量的注释；
- 编译器必须以 UTF-8 格式处理源文件，如果源文件未保存为 UTF-8 格式，则需先进行格式转换；
- 源文件的后缀名 `.vnl` 不区分大小写，`foo.vnl` 与 `foo.VNL` 会被视为同一个源文件。

模块内可以定义函数、类、接口、枚举、类型别名等元素。模块可以通过导入其他模块来使用其定义的元素，也可以被其他模块导入以供使用。模块的名称由源文件的名称决定，例如 `utils.vnl` 模块的名称为 `utils`，模块的命名只能使用小写字母、数字和下划线，同时不能以数字开头。

## 模块路径

模块路径是其所在的包的路径加上 `.`，再加上模块名。

注：
- 同一包内存在同名子包和模块时，优先匹配子包，实际使用时应避免包和模块重名

## 访问权限

模块自身的访问权限永远是公开的，即任何其他模块都可以通过导入声明将源模块导入到目标模块的顶层作用域中。
模块中的标识符访问权限默认是公开的，但可以通过在声明前面使用 `private` 关键字将其修饰为模块级私有，此时不能在模块外访问该标识符。

---

**附：Vanillang 模块文法产生式**

```ebnf
Module ::= (ImportDeclaration*) (TopIdentifierDeclaration*);
```
