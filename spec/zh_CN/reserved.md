# Vanillang 保留字

这些词在 Vanillang 中禁用或保留给未来使用，不能用作标识符：

| 保留字                       | 描述                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| `export`                     | 原本用于导出一个标识符，现已不使用                                           |
| `lambda`                     | 用于匿名函数表达式                                                           |
| `command`                    | 用于声明内联命令块                                                           |
| `async`、`await`             | 用于异步控制                                                                 |
| `generator`、`yield`、`from` | 用于生成器语法                                                               |
| `abstract`                   | 暂时不打算加入抽象类，但未来可能加入                                         |
| `decorator`、`decorate`      | 用于声明和调用装饰器                                                         |
| `record`                     | 用于声明一个纯数据类，留作语法糖                                             |
| `assert`                     | 用于断言检查                                                                 |
| `typeof`                     | 用于获取一个值的类型，返回字符串                                             |
| `defer`                      | 用于修饰一个在当前块级作用域结束时执行的语句                                 |
| `asset`                      | 用于声明一类数据包或资源包中的静态资源，保留给 Vanillang 2 使用              |
| `define`                     | 保留使用                                                                     |
| `!`                          | 非空断言运算符，用于获取 Optional\<T\> 包装的对象，如果对象为 none 则 reload |
| `...`                        | Rest 参数或 Spread 操作符                                                    |
