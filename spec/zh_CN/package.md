# Vanillang 包

Vanillang 的包是一个目录，该目录下可能包含一个或多个模块或子包，编译器在编译时，会将 `config` 中的 `packageRootPath` 的 `filename` 作为根包的包名，并将该目录下的所有源文件编译为该包的成员。
包具有这些特性：

- 包的命名只能使用小写字母、数字和下划线，同时不能以数字开头，以便映射到命名空间和路径
- 根包的包名会映射到 Minecraft 的命名空间，子包的包名会映射到数据包下的目录
- 包名不能是 Vanillang 关键字

## 包路径

包路径按下列规则构造：

- 根包的路径就是根包的名字
- 非根包的路径是其父级的路径加上 `.`，再加上包名

## 访问权限

包的访问权限始终是公开的。
