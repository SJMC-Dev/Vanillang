# Vanillang 运算符

这些符号用于表示基本的运算操作，或对运算符重载函数的调用
- 注意：Vanillang 仅支持在类或接口方法中重载运算符，不支持模块级运算符重载

## 数学运算符

| 运算符 | 描述                                                           | 是否支持重载 |
| ------ | -------------------------------------------------------------- | ------------ |
| `+`    | 二元运算符，用于两数相加，也可用于字符串拼接；也作为一元运算符 | 是           |
| `-`    | 二元运算符，用于两数相减；一元运算符，用于数值取反             | 是           |
| `*`    | 二元运算符，用于两数相乘                                       | 是           |
| `/`    | 二元运算符，用于两数相除，结果为浮点数                         | 是           |
| `//`   | 二元运算符，用于两数整除，结果为整数                           | 是           |
| `%`    | 二元运算符，用于两数取模，结果符号与被除数相同                 | 是           |
| `**`   | 二元运算符，用于幂运算                                         | 是           |
| `+=`   | 复合赋值运算符，等价于 `a = a + b`                             | 否           |
| `-=`   | 复合赋值运算符，等价于 `a = a - b`                             | 否           |
| `*=`   | 复合赋值运算符，等价于 `a = a * b`                             | 否           |
| `/=`   | 复合赋值运算符，等价于 `a = a / b`                             | 否           |
| `//=`  | 复合赋值运算符，等价于 `a = a // b`                            | 否           |
| `%=`   | 复合赋值运算符，等价于 `a = a % b`                             | 否           |
| `**=`  | 复合赋值运算符，等价于 `a = a ** b`                            | 否           |

注：复合赋值运算符在对应的二元运算符重载存在，且返回类型和左值类型相同时可用

## 赋值运算符

| 运算符 | 描述                                                                            | 是否支持重载 |
| ------ | ------------------------------------------------------------------------------- | ------------ |
| `=`    | 赋值运算符，将右值赋给左值                                                      | 否           |
| `??=`  | 空值合并赋值运算符，左值需为 Optional\<T\> 类型，当左值为 none 时将右值赋给左值 | 否           |

## 比较运算符

| 运算符 | 描述                                                                      | 是否支持重载              |
| ------ | ------------------------------------------------------------------------- | ------------------------- |
| `==`   | 等于运算符，比较两个值是否相等                                            | 是（返回值只能是 bool）   |
| `!=`   | 不等于运算符，比较两个值是否不相等                                        | 否（`==` 重载存在时可用） |
| `===`  | 相同运算符，比较两个引用类型的值是否引用同一个对象，不能用于 `Any` 类型   | 否                        |
| `!==`  | 不相同运算符，比较两个引用类型的值是否引用不同的对象，不能用于 `Any` 类型 | 否                        |
| `<`    | 小于运算符，比较左值是否小于右值                                          | 是                        |
| `>`    | 大于运算符，比较左值是否大于右值                                          | 是                        |
| `<=`   | 小于等于运算符，比较左值是否小于或等于右值                                | 是                        |
| `>=`   | 大于等于运算符，比较左值是否大于或等于右值                                | 是                        |

注：四个比较运算符重载使用符号 `<=>`，该重载返回 `vanillang.typesystem.Ordering?` ，为 `None` 时表示无法比较，否则 `Some(value)` 中的 `value` 含义如下：

- `vanillang.typesystem.Ordering.Less` 表示小于
- `vanillang.typesystem.Ordering.Equal` 表示等于
- `vanillang.typesystem.Ordering.Greater` 表示大于
  比较运算符重载不适用于 `==`，`vanillang.typesystem.Ordering.Equal` 仅用于判断 `<=` 和 `>=` 中的等号是否成立

## 逻辑运算符

| 运算符 | 描述                                             | 是否支持重载 |
| ------ | ------------------------------------------------ | ------------ |
| `&&`   | 逻辑与运算符，左值和右值都为真时结果为真         | 否           |
| `\|\|` | 逻辑或运算符，左值和右值有一个为真时结果为真     | 否           |
| `!`    | 逻辑非运算符，值为真时结果为假，值为假时结果为真 | 否           |

## 位运算符

| 运算符 | 描述                                                                   | 是否支持重载 |
| ------ | ---------------------------------------------------------------------- | ------------ |
| `&`    | 位与运算符，对两个整数的每一位执行逻辑与操作                           | 是           |
| `\|`   | 位或运算符，对两个整数的每一位执行逻辑或操作                           | 是           |
| `^`    | 位异或运算符，对两个整数的每一位执行逻辑异或操作                       | 是           |
| `~`    | 位非运算符，对一个整数的每一位执行逻辑非操作                           | 是           |
| `<<`   | 算术左移运算符，将一个整数的二进制表示向左移动指定的位数               | 是           |
| `>>`   | 算术右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补符号位 | 是           |
| `>>>`  | 逻辑右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补 0     | 是           |
| `&=`   | 位与赋值运算符，等价于 `a = a & b`                                     | 否           |
| `\|=`  | 位或赋值运算符，等价于 `a = a \| b`                                    | 否           |
| `^=`   | 位异或赋值运算符，等价于 `a = a ^ b`                                   | 否           |
| `<<=`  | 算术左移赋值运算符，等价于 `a = a << b`                                | 否           |
| `>>=`  | 算术右移赋值运算符，等价于 `a = a >> b`                                | 否           |
| `>>>=` | 逻辑右移赋值运算符，等价于 `a = a >>> b`                               | 否           |

注：复合赋值运算符在对应的位运算符重载存在，且返回类型和左值类型相同时可用

## 其他运算符

| 运算符 | 描述                                                                                                                 | 是否支持重载                       |
| ------ | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `.`    | 成员访问运算符，用于访问对象的属性或方法；包访问运算符，用于访问子包、模块或标识符                                   | 否                                 |
| `?.`   | 安全成员访问运算符，用于访问 Optional\<T\> 对象的属性或方法，如果对象为 none 则返回 none 而不是抛出异常              | 否                                 |
| `[]`   | 索引访问运算符，用于访问数组、列表或字典的元素；切片访问运算符，用于访问字符串的子串                                 | 是                                 |
| `()`   | 函数调用运算符，用于调用函数或方法                                                                                   | 是                                 |
| `?:`   | 条件表达式运算符，根据条件表达式的值选择返回结果                                                                     | 否                                 |
| `??`   | 空值合并运算符，当左值不为 none 时返回左值，否则返回右值，左值需为 Optional\<T\> 类型，右值不能为 Optional\<T\> 类型 | 否                                 |
| `..`   | 范围语法，用于生成一个包含起始和结束值的 Range 结构                                                                  | 是（仅支持左右操作数均存在的情况） |
