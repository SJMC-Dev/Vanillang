# Vanillang 字面量

字面量是表示特定值的字符串，不同类型的字面量遵循不同格式：

* 整型字面量（int 类型）

| 表示法 | 示例                                | 备注                       |
| ------ | ----------------------------------- | -------------------------- |
| 十进制 | `5`、`-9`、`16`、`1000000`、`-1234` | 存储为值对应有符号数的补码 |

* 字节型字面量（byte 类型）

| 表示法     | 示例                        | 备注                                              |
| ---------- | --------------------------- | ------------------------------------------------- |
| 十进制     | `1B`、`-3b`、`42B`、`127b`  | 后缀 `b/B` 不能省略；存储为值对应有符号数的补码   |
| ASCII 字符 | `'a'`、`'B'`、`'1'`、`'\\'` | 使用单引号；存储为对应的 ASCII 码；支持使用转义符 |

* 短整型字面量（short 类型）

| 表示法 | 示例                              | 备注                                            |
| ------ | --------------------------------- | ----------------------------------------------- |
| 十进制 | `2s`、`-32768S`、`256s`、`12345S` | 后缀 `s/S` 不能省略；存储为值对应有符号数的补码 |

* 长整型字面量（long 类型）

| 表示法 | 示例                                       | 备注                                                          |
| ------ | ------------------------------------------ | ------------------------------------------------------------- |
| 十进制 | `-32768L`、`2147483648l`、`1000000000000L` | 后缀 `l/L` 不能省略，建议使用大写；存储为值对应有符号数的补码 |

* 二进制、八进制、十六进制字面量（类型取决于上下文）

| 表示法   | 示例             | 备注                                                                                      |
| -------- | ---------------- | ----------------------------------------------------------------------------------------- |
| 二进制   | `0b10`、`0b1011` | 前缀 `0b` 不能省略，其中 `b` 须为小写；存储为字面真值，高位补 0                           |
| 八进制   | `0o77`、`0o23`   | 前缀 `0o` 不能省略，其中 `o` 须为小写；存储为字面真值，高位补 0                           |
| 十六进制 | `0x7F`、`0xc0c0` | 前缀 `0x` 不能省略，其中 `x` 须为小写；存储为字面真值，高位补 0；数位部分的字母大小写不限 |

* 布尔型字面量（bool 类型）

| 表示法 | 示例            | 备注               |
| ------ | --------------- | ------------------ |
| 布尔值 | `true`、`false` | 值为 true 或 false |

* 单精度浮点数（float 类型）

| 表示法     | 示例                                     | 备注                                                                                                                     |
| ---------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 十进制小数 | `.1f`、`-1.5F`、`1.0f`、`2.f`、`3.1415F` | 后缀 `f/F` 不能省略；整数或小数部分为 0 时可以省略不写；只有一个部分时小数点可以省略，也可以不省略                       |
| 科学记数法 | `1e3F`、`2.0e2f`、`3e-4`、`-2.e1F`       | 后缀 `f/F` 不能省略；小数部分为 0 时可以省略不写，此时小数点可以省略，也可以不省略；`e` 为小写，后面的整数表示 10 的幂次 |

* 双精度浮点数（double 类型）

| 表示法     | 示例                               | 备注                                                                                                   |
| ---------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 十进制小数 | `.1`、`-1.5d`、`1.0d`、`2.`、`6.D` | 后缀 `d/D` 可以省略；小数部分为 0 时可以省略不写，小数点不可省略                                       |
| 科学记数法 | `1e3d`、`2.0e2`、`3e-4D`、`-2.e1`  | 后缀 `d/D` 可以省略；小数部分为 0 时可以省略不写，小数点不可省略；`e` 为小写，后面的整数表示 10 的幂次 |

* 字符串字面量（string 类型）

| 表示法       | 示例                      | 备注                                                                      |
| ------------ | ------------------------- | ------------------------------------------------------------------------- |
| 普通字符串   | `"Hello, Vanillang!"`     | 使用双引号；支持转义符                                                    |
| 格式化字符串 | `f"the value is $(expr)"` | 以 `f/F` 开头；`$(expr)` 为插值语法；表达式 `expr` 必须可以被转换为字符串 |  |
| 原始字符串   | `r"Hello, \nVanillang!"`  | 以 `r/R` 开头；不支持转义符，不能包含双引号                               |

* 数组字面量（Array\<T\> 类型）

| 表示法              | 示例                  | 备注                                                     |
| ------------------- | --------------------- | -------------------------------------------------------- |
| 数组通用表示        | [expr1, expr2, expr3] | 所有表达式必须具有相同类型                               |
| SNBT 整型数组表示   | [I; expr1, expr2]     | 匹配 SNBT 整型数组；所有表达式必须能被转换成 int 类型    |
| SNBT 字节型数组表示 | [B; expr1, expr2]     | 匹配 SNBT 字节数组；所有表达式必须能被转换成 byte 类型   |
| SNBT 长整型数组表示 | [L; expr1, expr2]     | 匹配 SNBT 长整型数组；所有表达式必须能被转换成 long 类型 |

* 列表字面量（List 类型）

| 表示法 | 示例                  | 备注                       |
| ------ | --------------------- | -------------------------- |
| 列表   | [expr1, expr2, expr3] | 类型为 `vanillang.typesystem.List`，每个元素可以具有不同类型 |

* SNBT 复合标签字面量（Dict 类型）

| 表示法        | 示例                                         | 备注                                                           |
| ------------- | -------------------------------------------- | -------------------------------------------------------------- |
| SNBT 复合标签 | { key1: value1, key2: value2, key3: value3 } | 类型为 `vanillang.typesystem.Dict`，注意值不支持无引号字符串，键满足标识符命名规则时，引号可以省略 |

* 选择器字面量

| 表示法 | 示例                              | 备注                                                                                                                                                 |
| ------ | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 选择器 | `@a`、`@e[sort=nearest, limit=2]` | 类型为 `vanillang.typesystem.Selector`，遵循原版选择器的语法规范；注意由于参数 `nbt=` 性能开销过大且使用不便，故在 Vanillang 中不提供 `nbt=` 参数支持 |

* 范围字面量（Range 类型）

| 表示法 | 示例                                     | 备注                                                                                          |
| ------ | ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| 范围   | `0..99`、`-10..-1`、`..2`、`..-5`、`1..` | 类型为 `vanillang.typesystem.Range<T>`，与原版范围表示保持一致，左边表示最小值，右边表示最大值 |
