# Vanillang 元数据

Vanillang 元数据是标注在标识符声明或块语句上，提供给编译器以影响编译器行为的信息。

使用以下语法为声明或块语句添加元数据信息：

```text
metadata(元数据项列表)
```

其中，元数据项列表是由逗号分割的广义标识符，部分元数据项后面可以跟一个非格式化字符串字面量表示的元数据值。

目前支持的元数据项参考下表：

| 元数据项       | 是否携带元数据值 | 元数据值格式要求                                         | 用途                                                     |
| -------------- | ---------------- | -------------------------------------------------------- | -------------------------------------------------------- |
| `deprecated`   | 否               | -                                                        | 表示已弃用，外部使用时会产生警告                         |
| `nowarnings`   | 否               | -                                                        | 表示禁用警告，其标注的作用域内不会有警告产生             |
| `experimental` | 否               | -                                                        | 表示实验特性，外部使用时会产生警告                       |
| `gameversion`  | 是               | 一个支持的正式版版本号或一个由 `..` 分割的正式版版本范围 | 表示支持的游戏版本，若不匹配则被标注的部分会被编译器忽略 |

---

**附：Vanillang 元数据文法产生式**

```ebnf
Metadata ::= 'metadata' '(' MetadataTerm (',' MetadataTerm)* ')';
MetadataTerm ::= GeneralizedIdentifier [StringLiteral];
```
