# Vanillang 类型系统

Vanillang 支持基本类型、函数类型和自定义类型和任意类型，从语言层面上看，所有的基本类型均为值类型，函数类型和自定义类型通常为引用类型，引用本身也是特殊的值。

## 类型注解

类型注解是用来标注类型的语法，这些都是合法的类型注解：
```vanillang
int
float
bool
String
Optional<uint>
vanillang.types.Result<vanillang.types.Dict, vanillang.types.String>
Foo
Foo<Bar>
baz.Bar<Foo, baz.Qux>
ulong?
() -> void
(int, String?) -> Result<String, String>
((float) -> Optional<Player>)?
any
Result<any, String>
```

注：
- `void` 只能用来标注函数返回值，不能出现在其他地方
- `?` 是一种特殊的语法，它表示该类型可能为空值，`Foo?` 等价于 `vanillang.types.Optional<Foo>`
- `?` 作用于整个函数类型时，需要使用括号包围，否则会认为是作用于返回值
- 函数类型注解中，参数类型必须位于括号里面

## 类型转换

Vanillang 仅支持这些隐式类型转换：

- 目标类型是源类型的基类或接口时，可以隐式向上转换
- 目标类型是 `any`，源类型非空时，可以隐式向上转换
- 目标类型是可选类型，源类型非空时，可以隐式转换

## 类型收窄

Vanillang 类型收窄按照下列规则：

- `if`、`while` 语句中的表达式为 `instanceof` 表达式，且左操作数是一个局部变量或函数参数（含 `this`）时，所控制的语句中的该变量类型收窄
- `switch` 类型匹配语句捕获了一个局部变量或函数参数（含 `this`）时，每个 `case` 下的类型可以收窄为对应的类型

变量被收窄后，仍然可以被赋值（`this` 除外），但只能使用收窄后的类型及其子类的值来赋值。

## 基本类型

语言内置 11 个基本类型，具体信息如下：

| 类型名   | 解释         | 取值范围                                       |
| -------- | ------------ | ---------------------------------------------- |
| `byte`   | 有符号字节型 | -128 – 127                                     |
| `ubyte`  | 无符号字节型 | 0 - 255                                        |
| `short`  | 有符号短整型 | -32768 – 32767                                 |
| `ushort` | 无符号短整型 | 0 - 65535                                      |
| `int`    | 有符号整型   | -2147483648 – 2147483647                       |
| `uint`   | 无符号整型   | 0 – 4294967295                                 |
| `long`   | 有符号长整型 | -9223372036854775808 – 9223372036854775807     |
| `ulong`  | 无符号长整型 | 0 – 18446744073709551615                       |
| `float`  | 单精度浮点型 | -3.4×10<sup>38</sup> – 3.4×10<sup>38</sup>     |
| `double` | 双精度浮点型 | -1.79×10<sup>308</sup> – 1.79×10<sup>308</sup> |
| `bool`   | 布尔型       | `true`、`false`                                |

## 函数类型

一个函数类型应该由参数和返回值的类型共同决定，它的主要作用是让函数可以像普通的值或引用那样参与到表达式中。
相应的类型注解具体写法参考样例和文法产生式。

## 自定义类型

语言支持类、接口、枚举、枚举成员、不透明类型和类型别名六种自定义类型。

### 类

类表示同种对象的集合，它可以拥有以下成员：

- 实例属性
- 实例方法
- 静态属性
- 静态方法
- 构造器
- 运算符重载

关于类，还有这些特性：

- 类支持单继承，可以实现一个或多个接口
- 类的实例方法如果被重写，则该方法自动成为多态方法，绑定方式由编译时绑定变为运行时绑定，重写方法必须标注 `override` 关键字
- 使用 `final` 修饰的类表示该类不可被继承，尝试在类声明中继承 `final` 修饰的类会报编译错误

### 接口

接口表示一种抽象的协议或能力，它不能被实例化，成员只能是方法签名，具体来说来要满足以下特性：

- 只能是 `public` 访问权限
- 不支持继承
- 不能拥有实现
- 不能使用 `native` 等与实现相关的修饰符进行修饰
- 接口方法的返回类型必须显式声明

### 枚举

枚举表示一类匹配模式的集合，可以认为它是一个特殊的抽象类，其所有的枚举成员都是它的子类，以下是它的特性：

- 至少拥有 1 种枚举成员类型，不能是空的
- 可以定义实例方法、静态属性、静态方法和运算符重载
- 不支持继承，但可以实现接口
- 不能直接被实例化

### 枚举成员

枚举成员是定义在枚举中的一种具体的匹配模式，可以认为它是一个特殊的子类，它的特性如下：

- 可以拥有关联值，并在表达式中使用构造器语法实例化
- 没有关联值时，该枚举成员类型的值是唯一的，因此在表达式上下文中可以直接使用类型表示值
- 枚举成员关联值是只读的，不能使用赋值操作修改
- 枚举成员不能单独拥有方法，它可以使用所属枚举的方法

### 不透明类型

不透明类型表示由 Minecraft 进行管理，内部结构对 Vanillang 不可见的类型，语言无法管理它的生命周期，因此这类类型可能存在悬空的问题。
一个不透明类型只能拥有这些成员：

- 实例方法
- 静态方法
- 运算符重载

不透明类型不能拥有构造器，因为它的构造只能由 Minecraft 来完成，获取一个不透明类型的值，只能通过相关的函数调用来实现。
不透明类型的作用主要是为语言提供操作 Minecraft 原生对象的能力，它只能在标准库中定义，第三方库和数据包项目不能自定义不透明类型，尝试在根包包名不为 `vanillang` 的模块中定义不透明类型会报编译错误。
不透明类型也支持单继承和实现接口，但不能和类相互继承。

### 类型别名

类型别名用于重命名一个类型，它可以携带泛型参数。

注：
- 模块接口文件中的类型注解不可能出现类型别名，因为编译器在进行类型解析时会自动替换别名

## 任意类型

在部分无法编译时确定类型的上下文中，可以使用任意类型作为一个非空的类型，例如访问 `vanillang.types.Dict` 的值时。
所有类型都可以转换为任意类型，唯一一个例外是 `vanillang.types.Optional<T>`，因为它在语义上表示可能为空。
为了确保类型安全，在一个函数中，仅当所有 `return` 语句返回的值类型均为任意类型时，该函数的返回值类型才能被推断为任意类型。
关键字 `any` 表示一个任意类型的类型注解。

---

**附：Vanillang 类型注解文法产生式**

```ebnf
Type ::= FunctionType | NonFunctionType;
NonFunctionType ::= UnwrappedType ['?'];
UnwrappedType ::= PrimitiveType | CustomizedType | 'any' | '(' Type ')';
FunctionType ::= '(' [TypeList] ')' '->' ReturnType;
ReturnType ::= Type | 'void';
PrimitiveType ::= 'byte' | 'ubyte' | 'short' | 'ushort' | 'int' | 'uint' | 'long' | 'ulong' | 'float' | 'double' | 'bool';
CustomizedType ::= Identifier ('.' Identifier)* ['<' TypeList '>'];
TypeList ::= Type (',' Type)*;
```
