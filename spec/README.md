# Vanillang Language Specification

English | [简体中文](./README_zhs.md)

---

Vanillang is a domain-specific language designed for Minecraft vanilla development. It compiles high-level language code into Minecraft vanilla commands, allowing vanilla content creators to define game logic with high-level language syntax and freeing them from the tedium of writing vanilla commands.

This directory contains the language specification. The table below describes what each document covers.
