# Vanillang 语言规范

[English](./README.md) | 简体中文

---

Vanillang 是为 Minecraft 原版开发设计的领域特定语言，它通过将高级语言代码编译为 Minecraft 原版指令，以允许原版内容创作者使用高级语言语法定义游戏运行逻辑，解决原版指令编写过于繁琐的问题。

本目录为语言规范目录，下面介绍每个文档所描述的内容。

| 文档             | 内容简介           |
| ---------------- | ------------------ |
| `package.md`     | 包的相关规范       |
| `module.md`      | 模块相关规范       |
| `identifier.md`  | 标识符相关规范     |
| `keyword.md`     | 关键字及其用法     |
| `literal.md`     | 字面量定义         |
| `reserved.md`    | 保留字列表         |
| `declaration.md` | 声明规范           |
| `expression.md`  | 表达式规范         |
| `statement.md`   | 语句规范           |
| `operator.md`    | 运算符及其重载规范 |
| `type.md`        | 类型系统           |
| `generic.md`     | 泛型系统           |
| `metadata.md`    | 元数据及其用法     |
| `comment.md`     | 注释相关内容       |
| `vni.md`         | 模块接口文件规范   |
| `arc.md`         | 自动引用计数规范   |
